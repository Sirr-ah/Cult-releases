# Cult for Android

Official Android APK downloads for Cult. Application source is maintained separately.

## Updates with Obtainium

Install [Obtainium](https://github.com/ImranR98/Obtainium/releases), choose Add App, and use this source:

https://github.com/Sirr-ah/Cult-releases

Once the first signed release is available, Obtainium can install it and check future releases for updates. Allow installation permissions and background update checks. Android may require confirmation to install updates.

You can also download the APK from [Releases](https://github.com/Sirr-ah/Cult-releases/releases). SHA256SUMS.txt accompanies each release.

Existing debug builds may require a one-time uninstall before installing the signed release. Back up any local-only information first. Future releases use the same signing identity.

No APK has been published until a release appears on the Releases page.
